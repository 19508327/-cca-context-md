# UI 首次输出偏差需要用工程复现定位

- **场景**：UI 首稿的文字、Tab 间距、卡片层级、按钮样式与预期不一致，需要人工逐项指出。
- **核心判断**：现场出现过偏差，不等于已找出工程根因；AI 关于阴影/间距的解释不能替代复现证据。
- **下一步**：取得输入、版本、修复、回归结果，完成验收后才能关闭。

## 来源与原讨论

演示汇报了文字颜色、Tab 下间距、卡片层次和按钮样式偏差，人工指出后进行了调整。组件规范维护人被要求取得工程分析原因并修复。AI 对阴影或外层间距的解释尚未构成工程根因结论。修复效果需要对应项目复测。
