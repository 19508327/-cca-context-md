# 组件区块约束

- **场景**：只有 Token 时，单个控件可能符合参数，整页布局仍可能出现不合理嵌套、排版或多余说明。
- **核心判断**：会中倾向把 Token 落到可复用组件，并讨论以高频区块进一步约束生成。整页模板是否必要存在不同看法；组件和区块能够降低生成偏差是会中判断，未有本次对照实验证明。
- **下一步**：整理建议：对比仅 Token、Token 加组件、再加入区块时的页面结果，分别核对布局、状态和复用；验证范围由维护人确认。
