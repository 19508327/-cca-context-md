# 多风格 UI 以 G-common 基础约束为底座

讨论给新系统或明确换风格的场景提供模板选择、自身描述或参考图输入，配置颜色、字号、间距、密度和圆角等表现。以 G-common 组件和状态等约束为底座。允许配置项、约束方式及跨页面一致性仍待定义和验证，不能视为相关能力已完成。
