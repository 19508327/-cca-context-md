# 从需求到洞察递进的提示词分支先试三个方向

讨论要求先用 DeepDesign 打磨已有想法，再区分 UI Skill 已可用的方案与需要优化的部分。在此基础上，尝试约三个不同方向的结构化提示词，用于从产品需求继续递进到更深的洞察。方向数为初期试做目标，完成度和实际效果未获后续证据。
