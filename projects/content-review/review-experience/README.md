# 内容审核 · 送审与复核体验

发起人最需要知道“改哪一处、还在等谁”，审核人最需要知道“先看哪单、上次的问题改了吗”。方案用同一条意见串起素材、标注位置、修改版本和复核结果。例如，审核人在暂停的视频帧上标出问题，发起人只回传改动的素材，审核人对照旧版后在原意见下确认。

来源 `review-session-01` 为 2026-11-18 交互评审。各卡保留原转写时间点，供持有源文件的成员复核。此次会议记录涵盖演示、答疑及待决事项。[正式要求](Main/README.md)当前为空。
